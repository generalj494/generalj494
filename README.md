# 🌟 Neon Discord - Чат и Стриминг

Полнофункциональное приложение для чата и стриминга в реальном времени с неоновым дизайном и изометрическим фоном.

## ✨ Возможности

- 💬 **Чат в реальном времени** - общение с другими пользователями через WebSocket
- 📺 **Стриминг экрана** - трансляция экрана или окна в HD/FullHD качестве
- 👥 **Список пользователей** - отображение всех онлайн участников
- 🎨 **Неоновый дизайн** - уникальный визуальный стиль с изометрическим фоном
- 📱 **Адаптивный дизайн** - работает на всех устройствах
- 💾 **Локальное хранилище** - сохранение истории сообщений
- 🔄 **Автопереподключение** - автоматическое восстановление соединения

## 👥 Для общения нескольких пользователей

**Важно:** По умолчанию приложение работает в локальном режиме (один пользователь).

Для общения нескольких человек нужен WebSocket сервер. См. **[SETUP_CHAT.md](SETUP_CHAT.md)** для подробных инструкций.

**Быстрая настройка:**
1. Запустите `server.js` на хостинге с Node.js
2. В консоли браузера (F12) введите:
   ```javascript
   localStorage.setItem("wsUrl", "wss://ваш-сервер.com");
   location.reload();
   ```
3. Готово! Теперь все могут общаться в реальном времени

## 🚀 Быстрый старт

### ⭐ Вариант 1: Обычный хостинг (РЕКОМЕНДУЕТСЯ)

**Просто загрузите файлы на любой хостинг!**

1. Загрузите через FTP или файловый менеджер:
   - `index.html`
   - `css/style.css`
   - `js/app.js`

2. Откройте сайт в браузере - всё работает!

📖 **Подробная инструкция:** см. [HOSTING.md](HOSTING.md)

### Вариант 2: С Node.js сервером (для реального времени)

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер:
```bash
npm start
```

3. Откройте браузер и перейдите на `http://localhost:3000`

**Примечание:** Node.js сервер нужен только для синхронизации между разными пользователями. Без него приложение работает в локальном режиме.

## 🔧 Настройка

### Настройка WebSocket URL

В файле `js/app.js` измените URL WebSocket сервера:

```javascript
const CONFIG = {
    wsUrl: "ws://your-server.com:3000",
    // ...
};
```

Или установите через localStorage в консоли браузера:

```javascript
localStorage.setItem("wsUrl", "ws://your-server.com:3000");
```

### Переменные окружения

Для сервера можно использовать переменные окружения:

```bash
PORT=3000 npm start
```

## 🌐 Деплой на хостинг

### Vercel / Netlify (статический)

1. Загрузите проект в репозиторий GitHub
2. Подключите к Vercel/Netlify
3. Укажите корневую папку
4. Деплой автоматически выполнится

### Heroku / Railway (с сервером)

1. Установите Heroku CLI
2. Войдите: `heroku login`
3. Создайте приложение: `heroku create your-app-name`
4. Деплой: `git push heroku main`

### Обычный хостинг (cPanel, FTP)

1. Загрузите все файлы через FTP
2. Для работы сервера нужен Node.js хостинг
3. Запустите сервер через SSH: `node server.js`

## 🛠 Технологии

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js, Express, WebSocket (ws)
- **Стриминг**: WebRTC (getDisplayMedia API)
- **Хранилище**: LocalStorage

## 📝 Использование

1. **Вход**: Введите ваше имя и нажмите "Подключиться"
2. **Чат**: Напишите сообщение и нажмите Enter или кнопку "Отправить"
3. **Стриминг**: Нажмите "📺 Экран" или "🪟 Окно" для начала трансляции
4. **Каналы**: Переключайтесь между "Общий чат" и "Стримы"

## 🔒 Безопасность

- Валидация входных данных
- Защита от XSS (экранирование HTML)
- Ограничение длины сообщений
- Проверка подключений WebSocket

## 🐛 Известные проблемы

- Стриминг работает только в современных браузерах с поддержкой WebRTC
- WebSocket требует сервер для работы в реальном времени
- Некоторые браузеры могут блокировать всплывающие окна для стриминга

# ⚡ Быстрая настройка чата для нескольких пользователей

## 🎯 Самый простой способ (5 минут)

### Шаг 1: Запустите сервер

**Вариант A: На вашем компьютере (для тестирования)**

1. Откройте терминал в папке проекта
2. Выполните:
```bash
npm install
node server.js
```

3. Сервер запустится на `http://localhost:3000`

**Вариант B: На хостинге с Node.js**

1. Загрузите `server.js` и `package.json` на хостинг
2. Через SSH выполните:
```bash
npm install
pm2 start server.js
```

### Шаг 2: Настройте URL в браузере

1. Откройте сайт в браузере
2. Нажмите **F12** (открыть консоль)
3. Вставьте и выполните:

```javascript
localStorage.setItem("wsUrl", "ws://localhost:3000");
location.reload();
```

**Для удаленного сервера:**
```javascript
localStorage.setItem("wsUrl", "wss://ваш-сервер.com");
location.reload();
```

### Шаг 3: Готово! 🎉

Теперь откройте сайт в нескольких браузерах (или в режиме инкогнито) и общайтесь!

## 🌐 Если нет своего сервера

### Используйте бесплатные платформы:

#### Railway.app (Рекомендуется)

1. Зайдите на [railway.app](https://railway.app)
2. Войдите через GitHub
3. Создайте новый проект
4. Подключите ваш репозиторий
5. Railway автоматически запустит сервер
6. Скопируйте URL и используйте его как WebSocket URL

#### Render.com

1. Зайдите на [render.com](https://render.com)
2. Создайте новый Web Service
3. Подключите репозиторий
4. Укажите:
   - Build: `npm install`
   - Start: `node server.js`
5. Получите URL и настройте

## 🔍 Проверка работы

1. Откройте сайт в **двух разных браузерах**
2. Войдите под **разными именами**
3. Отправьте сообщение в одном браузере
4. Сообщение должно **появиться во втором браузере**

Если не работает:
- Проверьте консоль браузера (F12) - там будут ошибки
- Убедитесь, что сервер запущен
- Проверьте URL WebSocket

## 📝 Примеры URL

```javascript
// Локальный сервер
"ws://localhost:3000"

// Удаленный сервер без SSL
"ws://your-server.com:3000"

// Удаленный сервер с SSL (рекомендуется)
"wss://your-server.com"

// Тестовый сервис (только для проверки)
"wss://echo.websocket.org"
```

## 💡 Полезные команды

### Проверить текущий URL
```javascript
console.log(localStorage.getItem("wsUrl"));
```

### Сбросить на локальный режим
```javascript
localStorage.removeItem("wsUrl");
location.reload();
```

### Установить новый URL
```javascript
localStorage.setItem("wsUrl", "wss://новый-сервер.com");
location.reload();
```
